# OrangWallpapers Changer

A smol Windows app for changing your desktop wallpaper, from a URL, a local file, or a built-in collection.
This bypasses need for Windows activation, because microsoft blocks customization until activated.

## Download

Get `OrangWallpapers-Setup.exe` from the [latest release](https://github.com/Orang-Studio/OrangWallpapers/releases/latest) and run it. No admin rights needed. It installs to `%APPDATA%\OrangStudio\OrangWallpapers` and adds a Start menu shortcut. Uninstall it from Settings > Apps.

Works on Windows 8.1 (Sometimes), 10 and 11.

## Features

- Set a wallpaper from a URL, a local file or a built-in collection
- Thousands of extra wallpapers from community collections, sorted by category
- Fit modes: Fill, Fit, Stretch, Tile, Center, Span
- Resolution scaling: Original, Match Screen, or 4K down to 720p
- Light / Dark theme and Transparency Effects toggles
